8.53. File::ShareDir-1.118

allows you to access data files which have been installed by File::ShareDir::Install.

Approximate build time: less than 0.5 SBU
Required disk space: 159.8K

8.53.1. Installation of File::ShareDir

Prepare File::ShareDir for compilation: 

perl Makefile.PL

Compile the package: 

make

Extra Modules will most likely be needed, but to test the results, issue: 

make test

Install the package: 

make install

8.53.2. Contents of File::ShareDir

Installed module: none
Installed perl modules: File/ShareDir.pm
