8.44. Class::Inspector-1.36

Class::Inspector allows you to get information about a loaded class.

Approximate build time: less than 0.1 SBU
Required disk space: 155.2K

8.44.1. Installation of Class::Inspector

Prepare Class::Inspector for compilation: 

perl Makefile.PL

Compile the package: 

make

Extra Modules will most likely be needed, but to test the results, issue: 

make test

Install the package: 

make install

8.44.2. Contents of Class::Inspector

Installed module: none
Installed perl modules: Class/Inspector.pm, Class/Inspector/Functions.pm
