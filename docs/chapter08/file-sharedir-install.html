8.46. File::ShareDir::Install-0.14

File::ShareDir::Install allows you to install read-only data files from a distribution.

Approximate build time: less than 0.5 SBU
Required disk space: 260.4K

8.46.1. Installation of File::ShareDir::Install

Prepare File::ShareDir::Install for compilation: 

perl Makefile.PL

Compile the package: 

make

Extra Modules will most likely be needed, but to test the results, issue: 

make test

Install the package: 

make install

8.46.2. Contents of File::ShareDir::Install

Installed module: none
Installed perl modules: File/ShareDir/Install.pm
