3.14. Sed-4.9

The Sed package contains a stream editor.

Approximate build time: 0.1 SBU
Required disk space: 21 MB
SHA256 Checksum: 6e226b732e1cd739464ad6862bd1a1aba42d7982922da7a53519631d24975181

3.14.1. Installation of Sed

Prepare Sed for compilation:

./configure --prefix=/usr   \
            --host=$LFS_TGT \
            --build=$(./build-aux/config.guess)

Compile the package:

make

Install the package:

make DESTDIR=$LFS install

Details on this package are located in Section 5.32.2, “Contents of Sed.”
