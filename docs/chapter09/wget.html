9.25. Wget-1.25.0

The Wget package contains a utility useful for non-interactive downloading of files from the Web.

Approximate build time: 0.3 SBU (add 0.4 SBU for tests)
Required disk space: 33.7 MB (add 27 MB for tests)

Wget Dependencies

Recommended

Section 9.16, “libpsl-0.23.0”

Recommended at runtime

Section 9.22, “make-ca-1.16.1”

Optional

Section 9.14, “libidn2-2.3.8”,

9.25.1. Installation of Wget

Prepare Wget by running the following commands:

First, make a fix to make the package compatible with OpenSSL 4: 

NEW_LINE='#if !defined OPENSSL_NO_SSL3_METHOD && OPENSSL_VERSION_NUMBER < 0x40000000L'
sed -i "/SSL3/c $NEW_LINE" src/openssl.c

./configure --prefix=/usr      \
            --sysconfdir=/etc  \
            --with-ssl=openssl

Compile the package: 

make

To test the results, issue: 

make check

Install the package: 

make install

9.25.2. Command Explanations

--sysconfdir=/etc: This relocates the configuration file from /usr/etc to /etc.

--with-ssl=openssl: This allows the program to use openssl instead of "gnutls".
