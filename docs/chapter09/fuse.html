9.31. Fuse-3.18.2

9.31.1. Introduction to Fuse

FUSE (Filesystem in Userspace) is a simple interface for userspace programs to export a virtual filesystem to the Linux kernel. Fuse also aims to provide a secure method for non privileged users to create and mount their own filesystem implementations.

Approximate build time: less than 0.5 SBU
Required disk space: 33.2M

9.31.2. Kernel Configuration

Enable the following options in the kernel configuration and recompile the kernel if necessary: 

File systems --->
  <*/M> FUSE (Filesystem in Userspace) support                         [FUSE_FS]

Character devices in userspace should be enabled too for running the tests: 

File systems --->
  <*/M> FUSE (Filesystem in Userspace) support                         [FUSE_FS]
  <*/M>   Character device in Userspace support                           [CUSE]

9.31.3. Installation of Fuse

Prepare Fuse by running the following commands: 

sed -i '/^udev/,$ s/^/#/' util/meson.build
meson setup build --prefix=/usr --buildtype=release

Now Build Fuse with: 

ninja -C build

Testsuite of Fuse requires the pytest module

Now, Install: 

ninja -C build install
chmod u+s /usr/bin/fusermount3

If you wish to install the pre-built documentation, issue: 

cp -Rv doc/html -T /usr/share/doc/fuse-3.18.2
install -v -m644   doc/{README.NFS,kernel.txt} \
                   /usr/share/doc/fuse-3.18.2

9.31.4. Command Explanations

sed ... util/meson.build: This command disables the installation of a boot script and udev rule that are not needed.

9.31.5. Configuring fuse

9.31.5.1. Config Files

Some options regarding mount policy can be set in the file /etc/fuse.conf. To install the file run the following command: 

cat > /etc/fuse.conf << "EOF"
# Set the maximum number of FUSE mounts allowed to non-root users.
# The default is 1000.
#
#mount_max = 1000

# Allow non-root users to specify the 'allow_other' or 'allow_root'
# mount options.
#
#user_allow_other
EOF

Additional information about the meaning of the configuration options are found in the man page.

9.31.6. Contents

Installed Libraries: libfuse3.so
Installed Directory: /usr/include/fuse3 and /usr/share/doc/fuse-3.18.2
