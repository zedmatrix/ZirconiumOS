lxqt-openssh-askpass-2.3.0

Introduction to lxqt-openssh-askpass

The lxqt-openssh-askpass package is a GUI to query credentials on behalf of other programs.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

lxqt-openssh-askpass Dependencies

Required

liblxqt-2.3.0

Installation of lxqt-openssh-askpass

Prepare lxqt-openssh-askpass by running the following commands: 

cmake -B build -D CMAKE_INSTALL_PREFIX=/usr \
      -D CMAKE_BUILD_TYPE=Release
cmake --build build

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build
