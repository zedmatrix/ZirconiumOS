kate-25.08.3

Introduction to Kate

The Kate package contains an advanced KF6 based graphical text editor.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://download.kde.org/stable/release-service/25.08.3/src//kate-25.08.3.tar.xz

  • Download SHA256 Sum: c92eb8b5b81c9b5dc91b5c46d20b4f3ae0b7811114779fd8f92f153233fca90b

  • Download MD5 sum: a39d35117f9d5efe5472dd399b00a318

  • Download size: 45,991.5 KB

  • Estimated disk space required: 487,443.4 KB

  • Estimated build time: 4.68 SBU

Kate Dependencies

Required

KDE Frameworks-6.20.0 Kwindowsystem-6.20.0, extra-cmake-modules-6.20.0

Installation of Kate

Prepare Kate by running the following commands: 

cmake -B build -W no-dev               \
      -D CMAKE_INSTALL_PREFIX=/opt/kf6 \
      -D CMAKE_BUILD_TYPE=Release      \
      -D BUILD_TESTING=OFF
cmake --build build

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build

Contents

Installed Programs: kate and kwrite
Installed Libraries: Several plugins under /opt/kf6/lib/plugins
Installed Directories: /opt/kf6/lib/plugins/ktexteditor, /opt/kf6/lib/plugins/plasma/dataengine, /opt/kf6/share/doc/HTML/*/{kate,katepart,kwrite}, /opt/kf6/share/{kateproject,katexmltools}, and /opt/kf6/share/plasma/plasmoids/org.kde.plasma.katesessions
