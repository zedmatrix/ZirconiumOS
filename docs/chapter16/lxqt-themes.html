lxqt-themes-2.3.0

Introduction to lxqt-themes

The lxqt-themes package provides a number of graphics files and themes for the LXQt desktop.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/lxqt/lxqt-themes/releases/download/2.3.0/lxqt-themes-2.3.0.tar.xz

  • Download SHA256 Sum: e6ea956409b50e64e3eefe7b1b60c3ca9b9525dec3ff1eb53438ece55312ccb3

  • Download MD5 sum: 28d01d81463441e37042a34a611b4258

  • Download size: 27,643.2 KB

  • Estimated disk space required: 27,956.4 KB

  • Estimated build time: less than 0.1 SBU

lxqt-themes Dependencies

Required

lxqt-build-tools-2.3.0

Installation of lxqt-themes

Prepare lxqt-themes by running the following commands: 

cmake -B build -D CMAKE_INSTALL_PREFIX=/usr \
      -D CMAKE_BUILD_TYPE=Release
cmake --build build

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build

Contents

Installed Program: None
Installed Libraries: None
Installed Directories: /usr/share/lxqt/{graphics,themes,palettes,wallpapers}
