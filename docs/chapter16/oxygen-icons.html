oxygen-icons-6.0.0

Introduction to oxygen-icons

The oxygen icons theme is a photo-realistic icon style, with a high standard of graphics quality.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://download.kde.org/stable/oxygen-icons/oxygen-icons-6.0.0.tar.xz

  • Download SHA256 Sum: 28ec182875dcc15d9278f45ced11026aa392476f1f454871b9e2c837008e5774

  • Download MD5 sum: 7de8aed8caa14ccf5b4906e68c020d55

  • Download size: 433,722.9 KB

  • Estimated disk space required: 435,270.8 KB

  • Estimated build time: less than 0.1 SBU

oxygen-icons Dependencies

Required

extra-cmake-modules-6.20.0 and Qt-6.10.1

Installation of oxygen-icons

First, enable scalable icons: 

sed -i '/( oxygen/ s/)/scalable )/' CMakeLists.txt

Prepare oxygen-icons by running the following commands: 

cmake -B build -D CMAKE_INSTALL_PREFIX=/usr -W no-dev

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build
