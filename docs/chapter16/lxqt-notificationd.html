lxqt-notificationd-2.3.0

Introduction to lxqt-notificationd

The lxqt-notificationd package is the LXQt notification daemon.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/lxqt/lxqt-notificationd/releases/download/2.3.0/lxqt-notificationd-2.3.0.tar.xz

  • Download SHA256 Sum: c6b2bad0702e4d2af37f9f0755f2896ab23d1077a097cb1773bf4ae83deba740

  • Download MD5 sum: 16827e3ef769868617554956de4b5430

  • Download size: 572.8 KB

  • Estimated disk space required: 3,695.9 KB

  • Estimated build time: less than 0.5 SBU

lxqt-notificationd Dependencies

Required

liblxqt-2.3.0

Installation of lxqt-notificationd

Prepare lxqt-notificationd by running the following commands: 

cmake -B build -D CMAKE_BUILD_TYPE=Release  \
      -D CMAKE_INSTALL_PREFIX=/usr
cmake --build build

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build

Contents

Installed Programs: lxqt-config-notificationd and lxqt-notificationd
Installed Libraries: None
Installed Directories: /usr/share/lxqt/translations/lxqt-config-notificationd and /usr/share/lxqt/translations/lxqt-notificationd

Short Descriptions

lxqt-config-notificationd

is the lxqt-notificationd GUI configuration tool

lxqt-notificationd

is the LXQt notification daemon
