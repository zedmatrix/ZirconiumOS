sassc-3.6.2

Introduction to sassc

SassC is a wrapper around libsass, a CSS pre-processor language.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/sass/sassc/archive/3.6.2/sassc-3.6.2.tar.gz

  • Download SHA256 Sum: 608dc9002b45a91d11ed59e352469ecc05e4f58fc1259fc9a9f5b8f0f8348a03

  • Download MD5 sum: 4c3b06ce2979f2a9f0a35093e501d8bb

  • Download size: 89.3 KB

  • Estimated disk space required: 5,290.3 KB

  • Estimated build time: less than 0.1 SBU

SassC Dependencies

Required

libsass-3.6.6

Installation of sassc

autoreconf -fi

./configure --prefix=/usr

To Build the sassc wrapper, issue: 

make

This package does not come with a test suite.

Now Install the package, as the root user: 

make install
