lxqt-panel-2.3.0

Introduction to lxqt-panel

The lxqt-panel package contains a lightweight X11 desktop panel.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/lxqt/lxqt-panel/releases/download/2.3.0/lxqt-panel-2.3.0.tar.xz

  • Download SHA256 Sum: 556c8300a04affb68b14273ddd237c57f21f5493db089165fc7f4e3768f5ab7d

lxqt-panel Dependencies

Required

Layer-shell-qt-6.5.2, libdbusmenu-lxqt-0.3.0, liblxqt-2.3.0, lxqt-globalkeys-2.3.0, lxqt-menu-data-2.3.0, Solid-6.20.0, and menu-cache-1.1.1

Recommended

PulseAudio-17.0, libstatgrab-0.92.1 (network monitor and CPU load plugins), libsysstat-1.1.0 (CPU and network monitor plugins), libxkbcommon-1.13.0 (keyboard indicator plugin), and lm-sensors-3-6-2 (sensors plugin)

Installation of lxqt-panel

Prepare lxqt-panel by running the following commands: 

cmake -B build -D CMAKE_INSTALL_PREFIX=/usr \
      -D CMAKE_BUILD_TYPE=Release
cmake --build build

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build

Contents

Installed Program: lxqt-panel
Installed Libraries: several plugins under /usr/lib/lxqt-panel
Installed Directories: /usr/lib/lxqt-panel and /usr/share/lxqt/panel

Short Descriptions

lxqt-panel

is a lightweight Qt6 based panel for the LXQt Desktop
