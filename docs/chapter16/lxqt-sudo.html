lxqt-sudo-2.3.0

Introduction to lxqt-sudo

The lxqt-sudo package is a graphical front end to sudo and su respectively.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/lxqt/lxqt-sudo/releases/download/2.3.0/lxqt-sudo-2.3.0.tar.xz

  • Download SHA256 Sum: 79bf1e4eb39b61fd00221e908189ba1a4a06f0ee84d3bd1f31a81293f2b1cca1

  • Download MD5 sum: 3e6001b5f4556abc57281e44a7663a45

  • Download size: 319.2 KB

  • Estimated disk space required: 2,092.2 KB

  • Estimated build time: less than 0.1 SBU

lxqt-sudo Dependencies

Required

liblxqt-2.3.0

Installation of lxqt-sudo

Prepare lxqt-sudo by running the following commands: 

cmake -B build -D CMAKE_INSTALL_PREFIX=/usr \
      -D CMAKE_BUILD_TYPE=Release
cmake --build build

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build
