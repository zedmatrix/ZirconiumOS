libsysstat-1.1.0

Introduction to libsysstat

The libsysstat package contains a library used to query system information and statistics.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/lxqt/libsysstat/releases/download/1.1.0/libsysstat-1.1.0.tar.xz

  • Download SHA256 Sum: 996e5e8c43b1364a81a660b56956948c628e919f1d73554df6be152bbec8d430

  • Download MD5 sum: b21e0facd325c1d8e177121e2ac71e78

  • Download size: 79.5 KB

  • Estimated disk space required: 1,426.1 KB

  • Estimated build time: less than 0.1 SBU

libsysstat Dependencies

Required

lxqt-build-tools-2.3.0

Installation of libsysstat

Prepare libsysstat by running the following commands: 

cmake -B build \
      -D CMAKE_INSTALL_PREFIX=/usr \
      -D CMAKE_BUILD_TYPE=Release
cmake --build build

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build

Contents

Installed Program: None
Installed Library: libsysstat-qt6.so
Installed Directories: /usr/include/sysstat-qt6 and /usr/share/cmake/sysstat-qt6
