lxqt-policykit-2.3.0

Introduction to lxqt-policykit

The lxqt-policykit package is the LXQt PolicyKit agent.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/lxqt/lxqt-policykit/releases/download/2.3.0/lxqt-policykit-2.3.0.tar.xz

  • Download SHA256 Sum: 7ccf2547aa980eac6c4002acdea2c07b38ae017913a54f29d2221d18ee352cdf

  • Download MD5 sum: b70be830f40387207b6ad844daed6cd0

  • Download size: 163.8 KB

  • Estimated disk space required: 1,897.3 KB

  • Estimated build time: less than 0.5 SBU

lxqt-policykit Dependencies

Required

liblxqt-2.3.0 and polkit-qt-0.200.0

Installation of lxqt-policykit

Prepare lxqt-policykit by running the following commands: 

cmake -B build -D CMAKE_INSTALL_PREFIX=/usr \
      -D CMAKE_BUILD_TYPE=Release
cmake --build build

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build
