lxqt-about-2.3.0

Introduction to lxqt-about

The lxqt-about package provides the standalone LXQt “About” dialog.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/lxqt/lxqt-about/releases/download/2.3.0/lxqt-about-2.3.0.tar.xz

  • Download SHA256 Sum: 199056c2e848f8d22b4f6818ddca04305e849c22ac059b200df5bd574aaa12bd

  • Download MD5 sum: e6046469ea8838b65b5622d52bb280c1

  • Download size: 506.9 KB

  • Estimated disk space required: 2,689.4 KB

  • Estimated build time: less than 0.1 SBU

lxqt-about Dependencies

Required

liblxqt-2.3.0

Installation of lxqt-about

Prepare lxqt-about by running the following commands: 

cmake -B build -D CMAKE_INSTALL_PREFIX=/usr \
      -D CMAKE_BUILD_TYPE=Release
cmake --build build

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build
