libsass-3.6.6

Introduction to libsass

SassC is a wrapper around libsass, a CSS pre-processor language.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/sass/libsass/archive/3.6.6/libsass-3.6.6.tar.gz

  • Download SHA256 Sum: 11f0bb3709a4f20285507419d7618f3877a425c0131ea8df40fe6196129df15d

  • Download MD5 sum: afda97284d75a030cabadf5b9f998a3b

  • Download size: 1,584.3 KB

  • Estimated disk space required: 103,385.0 KB

  • Estimated build time: less than 1.0 SBU

Installation of libsass

autoreconf -fi

./configure --prefix=/usr --disable-static

To Build the library, issue: 

make

This package does not come with a test suite.

Now Install the library, as the root user: 

make install

Contents

Installed Programs: None
Installed Libraries: libsass.so.1.0.0, libsass.la
Installed Directories: /usr/include/sass
