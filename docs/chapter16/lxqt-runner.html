lxqt-runner-2.3.0

Introduction to lxqt-runner

The lxqt-runner package provides a tool used to launch programs quickly by typing their names.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/lxqt/lxqt-runner/releases/download/2.3.0/lxqt-runner-2.3.0.tar.xz

  • Download SHA256 Sum: 6d2fdd8d5a4395a3f5ec6cd27f6455d1a140f8a7e4ee81ac98af1b3f5989d5db

lxqt-runner Dependencies

Required

lxqt-globalkeys-2.3.0, Kwindowsystem-6.20.0, and muparser-2.3.5

Installation of lxqt-runner

Prepare lxqt-runner by running the following commands: 

cmake -B build -D CMAKE_INSTALL_PREFIX=/usr \
      -D CMAKE_BUILD_TYPE=Release
cmake --build build

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build

Using lxqt-runner

To use lxqt-runner, simultaneously press the Alt-F2 keys. A dialog window appears in the top center of the screen. When you start typing a command, a list of possible matches appears and changes as you keep typing.
