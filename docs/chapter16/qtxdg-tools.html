qtxdg-tools-4.3.0

Introduction to qtxdg-tools

The qtxdg-tools contains a CLI MIME tool for handling file associations and opening files with their default applications.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/lxqt/qtxdg-tools/releases/download/4.3.0/qtxdg-tools-4.3.0.tar.xz

  • Download SHA256 Sum: 6d84dc5016464741a6fbc466b94120267ea5333ebe037b9b0e1799846165ef96

  • Download size: 92.2 KB

  • Estimated disk space required: 1,205.3 KB

  • Estimated build time: less than 0.5 SBU

qtxdg-tools Dependencies

Required

libqtxdg-4.3.0

Installation of qtxdg-tools

Prepare qtxdg-tools by running the following commands: 

cmake -B build -D CMAKE_INSTALL_PREFIX=/usr \
      -D CMAKE_BUILD_TYPE=Release
cmake --build build

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build

Contents

Installed Directories: /usr/share/cmake/qtxdg-tools
