qps-2.12.0

Introduction to qps

The qps package contains a Qt process manager.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/lxqt/qps/releases/download/2.12.0/qps-2.12.0.tar.xz

  • Download SHA256 Sum: 76eb98b560e56b6a68b091e7ca2a4623d99f0b6106b181a7cc9e951352467004

  • Download MD5 sum: f086f0e88a1a8fe7425704d01a97680c

  • Download size: 3,233.7 KB

  • Estimated disk space required: 9,001.8 KB

  • Estimated build time: less than 1.0 SBU

qps Dependencies

Required

liblxqt-2.3.0

Installation of qps

Install qps by running the following commands: 

cmake -B build -D CMAKE_BUILD_TYPE=Release  \
      -D CMAKE_INSTALL_PREFIX=/usr
cmake --build build

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build

If you have xdg-utils-1.2.1 installed, as the root user, issue: 

xdg-icon-resource forceupdate --theme hicolor
