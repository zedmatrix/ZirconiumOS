lxqt-menu-data-2.3.0

Introduction to lxqt-menu-data

The lxqt-menu-data package contains compliant menu files for LXQt.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/lxqt/lxqt-menu-data/releases/download/2.3.0/lxqt-menu-data-2.3.0.tar.xz

  • Download SHA256 Sum: 703a44ba8a48927c073f2df200e330deb68b12f1589e06615603065f3d5b6e04

  • Download MD5 sum: 4f0181b7ce8db0682687a3686710fcdc

  • Download size: 205.5 KB

  • Estimated disk space required: 748.4 KB

  • Estimated build time: less than 0.1 SBU

lxqt-menu-data Dependencies

Required

lxqt-build-tools-2.3.0

Installation of lxqt-menu-data

Prepare lxqt-menu-data by running the following commands: 

cmake -B build \
      -D CMAKE_INSTALL_PREFIX=/usr \
      -D CMAKE_BUILD_TYPE=Release
cmake --build build

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build

Contents

Installed Directories: /etc/xdg/menus, /usr/share/desktop-directories, and /usr/share/cmake/lxqt-menu-data
