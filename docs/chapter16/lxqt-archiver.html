lxqt-archiver-1.3.0

Introduction to lxqt-archiver

The lxqt-archiver package is a simple and lightweight desktop-agnostic Qt file archiver.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/lxqt/lxqt-archiver/releases/download/1.3.0/lxqt-archiver-1.3.0.tar.xz

  • Download SHA256 Sum: 948655705e8e6a9c4c57f2d09b1134b4b23739c8cac0c39b09b04fb15d5375ef

  • Download MD5 sum: aec4d484bb8f666ee4a8e126925cf4ef

  • Download size: 2,411.4 KB

  • Estimated disk space required: 7,657.8 KB

  • Estimated build time: less than 0.5 SBU

lxqt-archiver Dependencies

Required

libfm-qt-2.3.0, liblxqt-2.3.0, and JSON-GLib-1.10.8

Installation of lxqt-archiver

Prepare lxqt-archiver by running the following commands: 

cmake -B build -D CMAKE_BUILD_TYPE=Release  \
      -D CMAKE_INSTALL_PREFIX=/usr
cmake --build build

This package does not come with a test suite.

Now Install the package, as the root user: 

cmake --install build
