adwaita-icon-theme-49.0

Introduction to Adwaita Icon Theme

The Adwaita Icon Theme package contains an icon theme for GTK+ 3 and GTK 4 applications.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://download.gnome.org/sources//adwaita-icon-theme/49/adwaita-icon-theme-49.0.tar.xz

  • Download SHA256 Sum: 65166461d1b278aa942f59aa8d0fccf1108d71c65f372c6266e172449791755c

  • Download MD5 sum: 8404c3a3950a99161da4b775c8c8236e

  • Download size: 27,066.4 KB

  • Estimated disk space required: 27,169.7 KB

  • Estimated build time: less than 0.1 SBU

Adwaita Icon Theme Dependencies

Required

GTK-3.24.51 or GTK-4.20.3, and librsvg-2.61.3

Installation of Adwaita Icon Theme

Prepare Adwaita Icon Theme by running the following commands: 

meson setup build --prefix=/usr
ninja -C build

This package does not come with a test suite.

Remove any old icons and install the new ones. As the root user: 

rm -rf /usr/share/icons/Adwaita/
ninja -C build install
