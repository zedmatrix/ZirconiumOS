11.39. rpcsvc-proto-1.4.4

11.39.1. Introduction to rpcsvc-proto

The rpcsvc-proto package contains the rcpsvc protocol files and headers, formerly included with glibc, that are not included in replacement libtirpc-1.3.7, along with the rpcgen program.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://github.com/thkukuk/rpcsvc-proto/releases/download/v1.4.4/rpcsvc-proto-1.4.4.tar.xz

  • Download SHA256 Sum: 81c3aa27edb5d8a18ef027081ebb984234d5b5860c65bd99d4ac8f03145a558b

  • Download MD5 sum: bf908de360308d909e9cc469402ff2ef

  • Download size: 168 KB

  • Estimated disk space required: 2.2 MB

  • Estimated build time: less than 0.1 SBU

11.39.2. Installation of rpcsvc-proto

Prepare rpcsvc-proto by running the following commands: 

./configure --sysconfdir=/etc

Build rpcsvc-proto by running the following commands: 

make

This package does not come with a test suite.

Now Install, as the root user: 

make install

11.39.3. Contents

Installed Programs: rpcgen
Installed Libraries: None
Installed Directories: /usr/include/rpcsvc

Short Descriptions

rpcgen

Generates C code to implement the RPC protocol
