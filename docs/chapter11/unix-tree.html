Introduction to unix-tree

The unix-tree application is useful to display a dictionary tree's contents, including files, directories, and links.

Package Information

  • Download (HTTP): https://gitlab.com/OldManProgrammer/unix-tree/-/archive/2.2.1/unix-tree-2.2.1.tar.bz2

  • Download SHA256 Sum: e911c4a2bea53586cc7be6f3d7d7f4d9c2f2bcbbad77d30700b31046e38f4bc5

  • Download MD5 sum: ada08dc80717b09e2041ac9276d7b854

  • Download size: 56 KB

  • Estimated disk space required: 588 KB

  • Estimated build time: less than 0.1 SBU

Installation of unix-tree

Install unix-tree by running the following commands: 

make

This package does not come with a test suite.

Now, as the root user: 

make PREFIX=/usr MANDIR=/usr/share/man install
