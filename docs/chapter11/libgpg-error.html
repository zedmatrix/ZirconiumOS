11.48. libgpg-error-1.56

11.48.1. Introduction to libgpg-error

The libgpg-error package contains a library that defines common error values for all GnuPG components.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://www.gnupg.org/ftp/gcrypt/libgpg-error/libgpg-error-1.56.tar.bz2

  • Download SHA256 Sum: 82c3d2deb4ad96ad3925d6f9f124fe7205716055ab50e291116ef27975d169c0

  • Download MD5 sum: af3544d4112b381edacca04a7e804999

  • Download size: 1.1 MB

  • Estimated disk space required: 12 MB (with tests)

  • Estimated build time: 0.1 SBU (with tests)

11.48.2. Installation of libgpg-error

To Prepare libgpg-error, issue: 

./configure --prefix=/usr

To Build libgpg-error, issue: 

make

To test the results, issue: 

make check

Now Install, as the root user: 

make install
install -v -m644 -D README /usr/share/doc/libgpg-error-1.56/README

11.48.3. Contents

Installed Programs: gpg-error, gpgrt-config, and yat2m
Installed Library: libgpg-error.so
Installed Directories: /usr/share/common-lisp/source/gpg-error, /usr/share/libgpg-error, and /usr/share/doc/libgpg-error-1.56

Short Descriptions

gpg-error

is used to determine libgpg-error error codes

gpgrt-config

is a pkg-config style tool for querying the information about installed version of libgpg-error

yat2m

extracts man pages from a Texinfo source

libgpg-error.so

contains the libgpg-error API functions
