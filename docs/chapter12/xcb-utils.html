The XCB utilities provide extensions that developers can use when making X Window software.

Utility libraries for XC Binding

  • Download Size: 1,681.8 KB

  • Build Size: 2,312.2 KB

  • Build Time: less than 0.5 SBU

Installation of xcb-util

To Configure the Package, issue these commands:

./configure --prefix=/usr    \
	--sysconfdir=/etc    \
	--localstatedir=/var \
	--disable-static

To Build the Package, issue these commands:

make

This package does not have a testsuite.

To Install the Package, issue these commands:

make install
