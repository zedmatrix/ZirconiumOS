Xorg7 Fonts

The Xorg font packages provide some scalable fonts and supporting packages for Xorg applications. Many people will want to install other TTF or OTF fonts in addition to, or instead of, these. Some are listed at "TTF-and-OTF-fonts".

  • Build Size: 1,278.1 KB

  • Build Time: less than 0.1 SBU

Installation of font-util

To Configure the Package, issue these commands:

./configure --prefix=/usr      \
         --sysconfdir=/etc    \
         --localstatedir=/var \
         --disable-static

To Build the Package, issue these commands:

make

This package does not have a testsuite.

To Install the Package, issue these commands:

make install
