xbitmaps-1.1.3

Introduction to xbitmaps

The xbitmaps package contains bitmap images used by multiple applications built in Xorg chapter.

This package is known to build and work properly using an LFS 12.4 platform.

Package Information

  • Download (HTTP): https://xorg.freedesktop.org/archive/individual//data/xbitmaps-1.1.3.tar.xz

  • Download SHA256 Sum: ad6cad54887832a17d86c2ccfc5e52a1dfab090f8307b152c78b0e1529cd0f7a

  • Download MD5 sum: 2b03f89d78fb91671370e77d7ad46907

  • Download size: 573.2 KB

  • Estimated disk space required: 639.3 KB

  • Estimated build time: less than 0.1 SBU

xbitmaps Dependencies

Required

util-macros-1.20.2

Installation of xbitmaps

Prepare xbitmaps by running the following commands: 

./configure --prefix=/usr        \
            --sysconfdir=/etc    \
            --localstatedir=/var \
            --disable-static

This package does not come with a test suite.

Now Install, as the root user: 

make install

Contents

Installed Programs: None
