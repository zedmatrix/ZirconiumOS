Dejavu Fonts TTF-2.37

The DejaVu fonts are a font family based on the Vera Fonts. Its purpose is to provide a wider range of characters while maintaining the original look and feel through the process of collaborative development. Font family based on the Bitstream Vera Fonts with a wider range of characters.

Package Information

  • Download (HTTP): https://sourceforge.net/projects/dejavu/files/dejavu/2.37/dejavu-fonts-ttf-2.37.tar.bz2

  • Extracted Size: 5,304 KB

  • Build Size: 11,625.6 KB

  • Build Time: less than 0.5 SBU

Dejavu Dependencies

Required

Fontconfig-2.17.1

Installation of Dejavu Fonts

To Install the font, as the root user:

install -v -d -m755 /usr/share/fonts/dejavu
install -v -m644 ttf/*.ttf /usr/share/fonts/dejavu

Now update the font cache 

fc-cache -v /usr/share/fonts/dejavu
