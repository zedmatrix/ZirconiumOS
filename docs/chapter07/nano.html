7.9. Nano-9.0

The Nano package contains a small, simple text editor which aims to replace Pico, the default editor in the Pine package.

Approximate build time: 0.2 SBU
Required disk space: 22.4 MB

7.9.1. Installation of Nano

Prepare Nano for compilation: 

./configure --prefix=/usr     \
            --sysconfdir=/etc \
            --enable-utf8     \
            --docdir=/usr/share/doc/nano-9.0

Compile the package: 

make

This package does not come with a test suite.

Install the package: 

make install
install -v -m644 doc/{nano.html,sample.nanorc} /usr/share/doc/nano-9.0

Details on this package are located in Section 8.76.2, “Configuring Nano.”
