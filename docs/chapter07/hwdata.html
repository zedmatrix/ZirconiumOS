7.2. hwdata-0.401

7.2.1. Introduction to hwdata

The hwdata package contains current PCI and vendor id data.

Package Information

  • Download (HTTP): https://github.com/vcrhonek/hwdata/archive/v0.401/hwdata-0.401.tar.gz

  • Download SHA256: e9ff93b9807cc014ed8f7f5cb5dc2c31e714058c82ddc59b7355f5c57c9b759e

  • Download MD5 sum: 9e4e329dc426a20cbf55b585a1f3acd5

  • Download size: 2.5 MB

  • Estimated disk space required: 9.7 MB

  • Estimated build time: less than 0.1 SBU

7.2.2. Installation of hwdata

Install hwdata by running the following commands: 

./configure --prefix=/usr --disable-blacklist

This package does not come with a test suite.

To Install this package, issue:

make install

7.2.3. Contents

Installed Programs: None
Installed Library: None
Installed Directory: /usr/share/hwdata
