# Beyond Linux From Scratch

## Scripts To Automate XML Parsing

>Usage: clone the repositories from [Linux From Scratch](https://www.linuxfromscratch.org)
  <br><br>basename.xsl - helper for blfs-parse_xml-to-zbc.xsl
  <br>blfs-parse_xml-to-zbc.xsl - main stylesheet to parse BLFS XML Directory/Files

> <br>parse-xml2zbc.sh - Script to take a single file or whole directory

> <br>createBuild.sh - Creates the Depends and Downloads Source Files

> <br>zinstall.sh - wrapper to check depends.sh, copy source files and execute zbuild
