## Chapter 14 - Media Back End

This chapter covers libraries, codecs, and frameworks required for a full-featured multimedia environment.  
Packages are grouped by category, but installation order is preserved.  

---

### Text Rendering & Graphics
- `fribidi` – Bidirectional text support.  
- `cairo` – 2D graphics library.  
- `bubblewrap` – Application sandboxing.  
- `fontconfig-pass2` – Font configuration and discovery.  
- `pango` – Text layout and rendering.  
- `graphviz` – Graph visualization tools.  
- `vala` – High-level programming language for GNOME libraries.  

---

### Time, Bluetooth & Core Media
- `gavl` – Multimedia library for uncompressed video/audio.  
- `libical` – iCalendar data handling.  
- `bluez` – Bluetooth protocol stack.  

---

### Audio Codecs
- `libogg` – Ogg container format.  
- `libvorbis` – Vorbis audio codec.  
- `speex`, `speexdsp` – Speech codec and DSP support.  
- `opus` – High-quality audio codec.  
- `lame` – MP3 encoder.  
- `flac` – Free Lossless Audio Codec.  
- `fdk-aac` – Fraunhofer AAC codec.  
- `liba52` – ATSC A/52 (AC-3) audio decoder.  

---

### Video Codecs & Subtitles
- `libaom` – AV1 codec.  
- `libass` – Subtitles renderer.  
- `x264`, `x265` – H.264 / H.265 encoders.  
- `sbc` – Low-complexity Subband Codec (Bluetooth audio).  

---

### Audio Frameworks
- `alsa-lib`, `alsa-utils` – ALSA sound system libraries & tools.  
- `faad2`, `faac` – AAC decoder/encoder.  
- `mpg123` – MP3 player/decoder.  
- `libsndfile` – Sound file handling.  
- `pulseaudio` – Sound server.  
- `sdl2` – Multimedia library.  

---

### Optical Media Support
- `libcddb` – CDDB database access.  
- `libcdio`, `libcdio-paranoia` – CD-ROM and ripping support.  
- `libdvdcss` – Access to encrypted DVDs.  
- `libdvdread`, `libdvdnav` – DVD playback libraries.  

---

### Image Libraries
- `libjpeg-turbo` – JPEG support.  
- `libtiff` – TIFF support.  
- `giflib` – GIF support.  
- `lcms2` – Color management.  
- `libmng` – MNG image format.  
- `libwebp` – WebP image format.  
- `glad` – OpenGL loader.  
- `libplacebo` – High-quality GPU rendering.  

---

### GNOME / GTK Graphics Stack
- `dbus-pass2` – D-Bus interprocess communication.  
- `at-spi2-core` – Assistive technology service provider.  
- `gsettings-desktop-schemas` – GNOME desktop schemas.  
- `gdk-pixbuf` – Image loading library.  
- `hicolor-icon-theme` – Base icon theme.  
- `gtk3` – GTK+ 3 toolkit.  
- `rustc` – Rust compiler.  
- `cargo-c` – Cargo C-ABI helper.  
- `librsvg` – SVG rendering library.  
- `pycairo` – Python bindings for Cairo.  
- `pygobject` – Python bindings for GObject.  
- `shaderc (glslc)` – Shader compiler.  

---

### GStreamer Multimedia Framework
- `gstreamer` – Core multimedia framework.  
- `cdparanoia` – Audio CD ripper.  
- `libgudev` – Device library for GObject.  
- `gst-plugins-base` – Base plugins for GStreamer.  
- `glib-networking` – Network support for GLib.  
- `libsoup` – HTTP client/server library.  
- `v4l-utils` – Video4Linux utilities.  
- `gst-plugins-good` – Good-quality plugins.  
- `soundtouch` – Time-stretching and pitch-shifting.  
- `libexif` – EXIF metadata library.  
- `libqrencode` – QR code generator.  
- `gst-plugins-bad` – Experimental plugins.  
- `gst-plugins-ugly` – Patent-encumbered plugins.  
- `json-glib` – JSON handling for GLib.  
- `libgusb` – USB library for GLib.  
- `colord` – Color management.  
- `gtk4` – GTK+ 4 toolkit.  
- `adwaita-icon-theme` – Default GNOME icon theme.  
- `gst-plugins-rs` – Rust-based plugins for GStreamer.  

---

### Fonts
- `libspiro` – Font manipulation library.  
- `fontforge` – Font editor.  
- `fonttools` – Font manipulation library (Python).  
- `liberation-fonts` – Free replacement for common fonts.  

---

### Sound Themes & Video Acceleration
- `libcanberra` – Sound event library.  
- `sound-theme-freedesktop` – Standard desktop sound theme.  
- `libvdpau-va-gl` – VDPAU/VA-API translation.  
- `libavif` – AVIF image format.  

---

### Video Plugins & Tools
- `frei0r` – Video effects plugins.  
- `xvid` – MPEG-4 video codec.  
- `svt-av1` – Scalable AV1 codec.  
- `dav1d` – AV1 decoder.  
- `ffmpeg` – Multimedia framework.  

---

### Audio & Video Integration
- `alsa-plugins` – ALSA plugin extensions.  
- `double-conversion` – Double to string conversion library.  
- `jasper` – JPEG-2000 library.  
- `libdaemon` – Simple daemon API.  
- `avahi` – mDNS/DNS-SD service discovery.  
- `pipewire` – Multimedia server.  
- `lua`, `luajit` – Scripting language support.  
- `wireplumber` – Session manager for PipeWire.  
- `uchardet` – Character set detection.  
- `libmad` – MPEG audio decoder.  
- `gst-libav` – FFmpeg plugin for GStreamer.  
- `mpv` – Media player.  

---

### Desktop Integration
- `xdg-desktop-portal` – Desktop integration services.  
- `gnome-desktop` – GNOME desktop support library.  
- `xdg-desktop-portal-gtk` – GTK backend for xdg-desktop-portal.  

---

### Lightweight Desktop Extras
- `imlib2` – Image loading and rendering.  
- `startup-notification` – Application startup feedback.  
- `openbox` – Lightweight window manager.  
- `icewm` – Lightweight desktop environment.
